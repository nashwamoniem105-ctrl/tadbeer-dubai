# موقع تدبير دبي - Tadbeer Dubai

موقع شركة تدبير للاستقدام - النسخة الكاملة (العربية والإنجليزية).

## محتويات المشروع
هذا المستودع يحتوي على ملفات الواجهة الأمامية (Frontend) للموقع كما هي موجودة في نسخة الإنتاج:
- **اللغة العربية والإنجليزية**: مدعومة بالكامل عبر ملفات الترجمة في `assets/i18n/`.
- **التصميم**: ملفات CSS وخطوط مخصصة (Somar).
- **الصفحات**: الصفحة الرئيسية (`home.html`) وبقية الصفحات المدمجة في ملفات JavaScript.

## التشغيل
بما أن هذه نسخة مبنية (Production Build)، يمكن تشغيلها باستخدام أي خادم ملفات ثابتة (Static Server) مثل:
```bash
npx serve .
```
أو رفعها مباشرة على منصات الاستضافة مثل Railway أو Vercel أو Netlify.
