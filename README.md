# تدبير دبي

موقع **شركة تدبير للاستقدام** — نسخة مستضافة على Railway مع نظام خلفي وقاعدة بيانات.

## بنية المشروع

| المجلد | الوصف |
| --- | --- |
| `client/` | واجهة Angular المبنية (شركة تدبير للاستقدام) |
| `server/` | النظام الخلفي (Express + SQLite) |

## النظام الخلفي (API)

يوفر الخادم واجهات برمجية (API) تدير قاعدة بيانات SQLite:

| المسار | الطريقة | الوصف |
| --- | --- | --- |
| `/api/health` | GET | فحص حالة الخدمة |
| `/api/users` | GET / POST | إدارة المستخدمين |
| `/api/requests` | GET / POST / PATCH | طلبات الخدمات (ساعة / شهرية) |
| `/api/contact` | GET / POST | رسائل نموذج التواصل |

## التشغيل

```bash
npm install
npm start
```

يعمل الموقع على المنفذ `PORT` (يحدده Railway تلقائيًا).

## النشر على Railway

المشروع منشور على Railway، ويتم ربط قاعدة البيانات والإعدادات تلقائيًا عبر بيئة التشغيل.
